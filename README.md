# BetterVitals

A light hardware monitor for Windows 11 that lives in the tray. It reads temperatures, loads, clocks, voltages, power, fans, memory, drives, network and FPS, keeps a history you can browse on charts with min, average and max for any time range, and can show a clean on-screen overlay that stays visible in games.

## Features

- **Sensors:** CPU, GPU, motherboard, RAM, drives, network, fans and FPS on Intel, AMD and NVIDIA hardware.
- **History:** choose what to record, browse it on charts and get min, average and max for any range. Or keep it live-only, with nothing written to disk.
- **Overlay:** pick a few values and a screen corner, or customize fonts, colors, sizes and layout. It works over desktop apps and games and stays out of streams and recordings.
- **Light:** built to use as little CPU and memory as possible while it records.
- **Offline:** the only connection is an optional update check.
- **Languages:** English and Polish.
