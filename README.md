# BetterVitals

A light hardware monitor for Windows 11 that lives in the tray: temperatures, loads, clocks, power, fans and FPS, live and over time.

![The tray flyout with CPU and GPU temperature and load next to the Overview page with key values and sparklines](media/hero.png)

## History

Choose what to record and browse it on charts. Drag across a range to get its min, average and max, and when they happened.

![The History page: six hours of CPU, GPU and GPU Hot Spot temperatures with an evening game selected and its min, average and max](media/history.png)

## Overlay in games

The values you pick, on top of any game or app. It draws in its own window, nothing is injected into the game, and it stays out of streams and recordings.

![The overlay in a game, one row per component: FPS with a small graph; CPU temperature and core clocks; GPU temperature, GPU Hot Spot and GPU clock](media/overlay.png)

## Set it up in a minute

Click the values you want, then pick a layout (a list, a row per component or one line) and a corner; the preview shows the result. Advanced mode changes fonts, colors and sizes, moves single values between rows and detaches them into boxes of their own anywhere on the screen.

![The overlay editor in simple mode: GPU values picked as tiles, a live preview on a monitor and a close-up of the overlay in rows](media/overlay-editor.png)

## Sensors

Two switches per sensor: record it, show it on the overlay. Hover a name for a short explanation of what it measures.

![The Sensors page with History and Overlay switches per sensor and the explanation bubble for GPU Hot Spot](media/sensors.png)

- **Hardware:** CPU, GPU, motherboard, RAM, drives, network, fans and FPS on Intel, AMD and NVIDIA.
- **Light:** built to use as little CPU and memory as possible while it records. Live-only mode writes nothing to disk.
- **Offline:** the only connection is an optional update check.
- **Languages:** English and Polish.
